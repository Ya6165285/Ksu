# Рилсы из второго YouTube-ролика

- `plan.py` — 12 рилсов (n1–n12): хуки, фрагменты по фразам расшифровки, вставки, зумы.
  В конец каждого: «мост» про отношения из этого видео + фрагмент про бесплатный урок
  из первого видео (src 1) + обложка урока + «напиши МАРШРУТ».
- `reel.py` — рендер, умеет собирать клипы из двух исходников (поле `src` у слова,
  `sources`/`audios`/`gains` в спецификации).
- `mkpage.py` — сжатие и страницы для просмотра.
- Новые кадры n01–n12 описаны в `../broll_catalog.txt`.
