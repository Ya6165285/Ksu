# Нарезка YouTube → рилсы (стиль эталона)

- `plan.py` — список рилсов: фразы-границы в исходнике, хук (разметка: обычный текст = Inter, `*курсив*` / `^прямой^` = Cormorant), вставки, наезды, тип концовки (`own` — Ксюша говорит про урок + обложка, `card` — финальная карточка МАРШРУТ).
- `reel.py` — рендер: чёрный 9:16, хук сверху, горизонтальное видео полосой по центру, субтитры по слову под ним, карточки-вставки снизу, наезды на весь экран, тихие «попы», концовка.
- `mkpage.py` — страницы с плеером и кнопкой «Скачать» (по 2 рилса).
- `broll_catalog.txt` — что лежит в папке вставок.

Порядок: транскрипция (GigaAM) → `python3 plan.py` → `python3 reel.py specs/rN.json out/rN.mp4` → `python3 mkpage.py`.
